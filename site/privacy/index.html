Privacy, kept local.

Firebase Environment Doctor does not collect, transmit, or sell personal data. The CLI has no telemetry. Its default checks read files and environment metadata on your computer and write nothing.

Optional network checks

Network checks run only when you pass --network. The CLI then invokes the documented firebase login:list --json and firebase projects:list --json commands. Those requests are handled by Firebase under your existing CLI configuration. The doctor uses the results to report login validity and project visibility; it does not print or retain tokens.

Website

This website has no analytics, advertising, cookies, local storage, third-party scripts, or form submission. The diagnostic demo uses static examples in your browser and sends no data.

Your control

Do not use --network if you want fully offline operation. Remove the binary to uninstall it; the doctor creates no account and stores no profile.
