How this Firebase check handles data.

The CLI reads your local project files. Its default check does not make a network request or change Firebase settings.

Optional Firebase checks

Passing --network runs firebase login:list --json and firebase projects:list --json. The doctor does not print credential values in its report.

Website demo

The demo page uses bundled sample data. It keeps its reset state under a demo-only browser storage key and does not send your project data.

Website requests

This static site uses no analytics, advertising, cookies, or third-party scripts. It loads only its own files.

Your control

Use the default command for local checks. Use --network only when you want Firebase access checked.
